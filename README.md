# Cavite State University - Naic Registrar Website

A web-based information and management platform designed for the **Cavite State University – Naic Campus Registrar**. This project aims to provide students, faculty, and registrar staff with easier access to academic services, announcements, and registrar-related information through a user-friendly online system.

## 📌 Project Overview

The Cavite State University – Naic Registrar Website is developed to improve the accessibility and efficiency of registrar services by providing a centralized online platform. The website helps students stay informed about important academic updates, registrar procedures, and available services.

## 🎯 Objectives

* Provide students with easy access to registrar information and announcements.
* Improve communication between the registrar's office and students.
* Organize academic-related resources and services in one platform.
* Create a more convenient digital experience for registrar transactions and inquiries.

## ✨ Features

* 📢 Registrar announcements and updates
* 📄 Academic forms and downloadable documents
* 🏫 Registrar office information
* 📚 Student service information
